# 群聊机器人 (`com.example.group-chat-bot`)

TraceMemo 官方扩展模板。结合 TraceMemo 已配置的 AI 模型与文字转语音（TTS）音色，在指定微信群聊中按角色设定自然接话，支持单群长期记忆与随机回复文字 / 随机发送语音。

## 核心特性

1. **多套群聊人格（Persona）**：内置「日常群友」「技术搭子」「温柔捧场王」「幽默气氛组」四套预设人格，支持新建、修改或删除自定义人格（独立配置人设背景、说话风格、字数上限与追问约束），并可为不同微信群绑定不同人格。
2. **短期上下文 + 单群长期记忆（Memory）**：
   - **短期记忆**：接话时自动读取本群最近 N 条文本消息作为多轮对话上下文。
   - **长期记忆**：按群独立维护「固定背景记忆（手动置顶的群规、群友称呼偏好）」与「AI 自动提炼的互动摘要（常聊话题、近期约定）」。可按对话轮数自动更新，也可在配置页随时手动触发 AI 提炼或修订。
3. **自然群聊节奏控制**：支持「仅 @我」「命中唤醒词」「@我 或唤醒词」「自然活跃接话（@我必回 + 普通群消息按概率随机搭话）」四种触发模式，区分直接唤醒冷却与环境闲聊冷却，并支持重复表达抑制。
4. **随机回复文字 / 随机发送语音 + TraceMemo 音色同步展示**：
   - 配置页直接展示 TraceMemo「设置 → 文字转语音」中当前选定的音色（名称、ID、标签、合成模型与样本试听）。
   - 支持「随机混合（按概率随机回复文字或发送语音）」「仅回复文字」「仅发送语音」三种模式，单群可独立覆盖；当语音未就绪或发送失败时支持自动降级为发送文字。

## 申请权限

| 权限 | 用途 |
| --- | --- |
| `messages.subscribe` | 接收微信群聊新文本消息事件 |
| `messages.query` | 读取触发群聊最近的上下文消息 |
| `contacts.list` | 在配置页读取群聊列表供勾选生效范围 |
| `wechat.send.text` | 经 TraceMemo Gateway 发送群聊文字回复 |
| `wechat.send.voice` | 经 TraceMemo 文字转语音服务与 Gateway 发送群聊语音气泡 |
| `ai.chat` | 调用 TraceMemo 已配置的 AI Provider 进行思考回复与记忆提炼 |
| `storage` | 保存机器人配置、单群长期记忆与今日统计 |
