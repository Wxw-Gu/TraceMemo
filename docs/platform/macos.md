# macOS 数据访问与系统权限

## 你什么时候会看到这些提示

TraceMemo 需要读取微信本地数据。macOS 会根据系统版本、微信状态和安全设置，要求应用完成授权；自动获取数据库密钥时，页面可能提示暂时调整系统安全设置。

## 推荐步骤

1. 先启动 TraceMemo，阅读连接页面显示的当前前置条件。
2. 确认微信数据目录指向当前账号。
3. 只在页面明确要求时处理系统授权或 SIP；关闭 SIP 的具体步骤见[关闭 SIP 教程](../mac-disable-sip.md)，按页面提示完成密钥获取后，恢复你平时使用的安全设置。
4. 返回应用重新检测账号、数据库和图片资源状态。

不要直接复制网上针对其他微信版本的命令。系统授权失败时，记录 macOS 版本、微信版本和页面错误，再按[排障文档](../user-guide/troubleshooting.md#连接微信失败)处理。

## 提示「无法读取微信数据库」时

**这是故障恢复步骤，不是安装前置条件。** 能正常连接的用户不需要做任何权限设置。

如果你在连接页看到「最近验证结果：无法读取微信数据库」（错误码 `DATABASE_PERMISSION_DENIED`），并且已经确认微信数据目录**实际存在**（例如在终端里能列出 `db_storage/session/session.db`），那说明是 **TraceMemo 这个进程**读不到，而不是文件缺失。

macOS 27 及更高版本对其他应用的容器数据有更严格的访问控制。给 TraceMemo 授予「完全磁盘访问权限」：

1. 打开 **系统设置 → 隐私与安全性 → 完全磁盘访问权限**
2. 找到 **TraceMemo**，打开开关
3. **重新启动 TraceMemo**（该授权只在进程下次启动时生效）
4. 回到连接页重试

### 为什么终端能读、TraceMemo 读不了

macOS 的隐私权限按**应用进程的身份**判定，而不是按文件系统的用户身份。同一个用户在终端里能读到文件内容，不代表 TraceMemo 进程也有权限 —— 两者走的是不同的授权判定。所以「终端能读」不能用来排除权限问题。

### 不要做的事

上面这条路径**只涉及给 TraceMemo 授权**。以下做法都不需要，而且有风险：

- 关闭 SIP
- `chmod` / `chown` 整个微信目录
- 用 `sudo` 启动 TraceMemo
- 修改微信数据库文件权限

「无法读取微信数据库」与 SIP 不是同一个问题；改动微信数据目录的权限还可能影响微信自身的正常运行。

## SIP 风险

关闭 System Integrity Protection 会降低 macOS 对系统文件和进程的保护。它不是日常使用 TraceMemo 的功能开关，也不应长期保持关闭。只有在你理解风险、确认页面要求且完成必要操作时才处理；完成后按 Apple 官方方式重新启用。

## 应用无法打开

如果 macOS 阻止未验证的应用，使用系统“隐私与安全性”中的“仍要打开”选项。不要为了绕过提示下载来历不明的补丁或替换应用文件。

## Intel 与 Apple Silicon

TraceMemo 同时支持两种 Mac 架构：

- **Apple Silicon（M 系列、`arm64`）**
- **Intel Mac（`x64`）**

从 Releases 下载与你 Mac 处理器匹配的构建：

- Apple Silicon：`tracememo-<版本号>-arm64.dmg`
- Intel：`tracememo-<版本号>-x64.dmg`

两种架构都可以通过应用内的连接流程自动获取微信数据库密钥。首次连接时，TraceMemo 会根据当前机器架构进入对应的流程，按连接页面提示操作即可。

Apple Silicon 和 Intel 已适配微信 macOS `4.1.13`。不同架构、微信版本和系统授权状态可能导致连接结果不同；文档不对所有组合做兼容性保证。
