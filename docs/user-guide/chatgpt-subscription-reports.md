# 使用 ChatGPT 订阅生成群聊日报

在「设置 → AI 模型」连接 ChatGPT，完成浏览器授权后选择可用的订阅模型。凭据由系统安全存储加密保存在本机；账号切换、重新授权和断开连接也在这里操作。

## 手动生成

在「日报」选择来源群、时间范围和 ChatGPT 订阅文字模型。每次提交前，应用会确认是否允许将本次输入发送给 OpenAI。图片理解继续使用单独配置的图片模型。

## 定时生成并保存本地

1. 打开「自动化 → 定时日报」，新建规则或编辑已有规则。
2. 设置时间、来源群、消息范围和文字模型。
3. 选择「仅保存本地」。此模式不要求微信发送组件，生成的 HTML、PNG 和记录进入「日报历史」。
4. 使用订阅模型时，勾选允许该规则按时发送输入给 OpenAI，再启用并保存。

输入可能包含消息正文、转录文字和成员名称。修改来源群、模型、消息范围、消息类型或成员名称模式后，需要重新确认授权。未配置、已断开或不再可用的指定模型会报错，不会自动改用其他 API 供应商。

新规则默认仅保存本地。旧规则没有保存方式字段时，仍保留原来的微信投递行为；升级不会自动启用旧规则。独立配置的异常通知仍遵循通知设置。

## 运行条件

定时器需要应用运行、数据库已连接和电脑处于唤醒状态。微信需同步所选日期的消息；本机没有消息时不会调用模型，也不会生成空白日报。

应用恢复运行时，只补最近一个尚未消费的每日时间点，不逐日补全部历史。消息日期按实际执行当天计算。例如隔天恢复时，「昨天」指恢复当天的前一天。正常完成的时间点会持久化防重；立即执行不消耗计划时间点。进程在保存完成前意外退出时，恢复后可能重试。

生成失败可在「自动化 → 执行日志」查看原因。授权或模型不可用时，先修复连接并检查规则；无消息时，先确认微信已同步相应日期。
